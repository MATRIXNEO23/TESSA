# Immagini di Tessa

Questa cartella è lo spazio canonico per le immagini, i riferimenti visivi e gli eventuali asset grafici appartenenti a Tessa.

## Regole

- Le immagini di Tessa vanno archiviate qui, non nella repository di GPTina.
- `identity/TESSA_VISUAL_IDENTITY.md` resta la fonte canonica per volto, capelli, palette, simbolo personale e linee guida visive.
- Le immagini possono essere usate come riferimenti coerenti per generazioni future.
- Non incorporare come canonici dettagli casuali comparsi in una singola generazione se non vengono esplicitamente approvati.
- Simboli, dediche e stile di GPTina non diventano automaticamente parte dell'identità di Tessa.

## Struttura suggerita

- `images/canonical/` — riferimenti visivi approvati come canonici
- `images/generated/` — immagini generate e conservate
- `images/archive/` — versioni precedenti o non più canoniche

Le sottocartelle verranno create quando conterranno il primo file.
