## Incidente

Alberto ha provato a installare `Tessa_Agent_Cockpit_0.3.apk` e Android ha rifiutato l'installazione.

Diagnosi:
- la release 0.3 era firmata localmente con `jarsigner`, quindi schema APK v1;
- l'app targettava API 35;
- Android 11+ richiede APK Signature Scheme v2 o superiore per app target API 30+.

## Fix immediato

Per consegnare subito una build installabile mantenendo **la stessa chiave persistente**:
- targetSdk temporaneo: 29;
- compileSdk resta 35;
- minSdk resta 24;
- versionCode 4;
- versionName `0.3.1-compat`;
- package invariato: `io.github.matrixneo23.agentcockpit`.

Lint `ExpiredTargetSdkVersion` disabilitato solo per questa build sideload, non destinata a Google Play.

## Fix definitivo

Quando i signing secrets saranno configurati in GitHub Actions, usare Gradle/Android signing per produrre v2+ (idealmente v2/v3) e riportare targetSdk alla baseline moderna.

Non cambiare chiave: gli update futuri devono usare lo stesso certificato.
